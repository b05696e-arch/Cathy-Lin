# 臨床技能中心教具借用管理

## 開啟方式

直接以 Chrome、Edge 或其他現代瀏覽器開啟 `index.html`，不需要安裝套件或啟動伺服器。

## 功能

- 依教具清單建立 36 項教具，可依名稱、廠牌、型號及類別搜尋與篩選。
- 登記借用人、借用單位、數量、預計歸還日期和備註。
- 依借用中數量自動計算剩餘庫存，防止借超過現有數量。
- 查看逾期借用，並在歸還時回補可借數量。
- 將借用紀錄匯出為 UTF-8 CSV，方便用 Excel 開啟。

## 資料儲存

借用紀錄保存在目前瀏覽器的本機儲存空間。資料不會自動同步到其他電腦或瀏覽器；換設備前請先在「借用紀錄」匯出 CSV。清除瀏覽器網站資料也會移除本機紀錄。

目前版本適合在單一管理工作站試用。多人同時操作或跨裝置共用需要另外接上資料庫、登入和伺服器。

## 清單來源

庫存項目、數量、廠牌與型號依專案內的「臨床技能中心教具.pdf」建立。PDF 未提供明確廠牌或型號的欄位以「未標示」呈現；教具類別是為方便搜尋而整理。
